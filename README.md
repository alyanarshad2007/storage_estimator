# Storage Estimator - Feature Version

1. Purpose
This Python program displays the total, used, and free storage on a selected drive. It also checks whether enough free space is available for additional storage.

2. How to Run

1. Make sure Python 3 is installed.
2. Open a terminal in the project folder.
3. Run the program:

   `python storage_estimator.py`

4. Enter a drive path, such as `C:/`.
5. Enter the required storage in MB.

## Example Input/Output

```text
Enter drive path (e.g., C:/): C:/
Total storage: 200.00 GB
Used storage: 120.00 GB
Free storage: 80.00 GB
Enter required storage (MB): 280
"Sufficient storage available."```
